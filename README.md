# Library-Management
A Java-based Library Management System for managing books, members, and basic book issue and return operations.
## Project Overview
The Library Management System is designed to simplify basic library operations such as viewing books, issuing books, and returning books.
The project uses Object-Oriented Programming concepts to represent books, members, and library operations.
The current version provides a simple console-based interface and can be extended with MySQL database integration for permanent data storage.
## Features
- View available books
- Add books
- Add library members
- Issue books
- Return books
- Check book availability
- Display book details
- Console-based menu
- Object-Oriented design
## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Java Scanner
- JDBC
- MySQL
- VS Code / IntelliJ IDEA / Eclipse

- Run Main.java
